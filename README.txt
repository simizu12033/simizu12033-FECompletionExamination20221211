2022.12.11 FE修了試験｜略語・選択肢比較補強版 v5

今回の補強
問32ではDHCP・ICMP・SMTP・SNMPの正式名称、日本語の意味、役割を解説冒頭の表で比較し、表から4種類全てのカードへ移動できます。各カードには単語の分解と用途の例を補いました。
全体では47枚のカードへ略語の正式名称と日本語の意味を追加し、15問に比較表を追加。正式名称でも検索できます。
略語の正式名称一覧.mdも同梱しています。197枚のカードIDは前版から維持しました。

重要用語カードの修正
全320選択肢をそのまま暗記カードへ転記する方針を改めました。利用率0.4、16進の解答列、実行順ア、図の識別名、計算結果などは用語カードから除外。用語・概念を197枚に整理し、同じ意味のカードは統合しています。
例：問2は「回線利用率」「待ち行列」、問6は「偶数パリティ」、問17は「競合状態」「排他制御」、問78は各段階の利益を収録。
正答ではない選択肢に登場する実際の用語（オーバフロー、クイックソート等）も含めています。選択肢の意味や判定理由は全320件とも各問題の解説に残しています。
カードの表は用語、裏は意味と見分け方。正答・誤答でカードを分類する操作をなくし、関連する問題番号で探せます。
重要用語カード一覧.mdに全197枚の見出し・意味・注意点を収録しました。

利用方法
ZIPを展開してindex.htmlを開いてください。外部ライブラリは不要です。
GitHub Pagesを更新する場合は、フォルダ内の全ファイルをassetsの階層ごと置き換えてください。ZIPそのものを配置する方式ではありません。キャッシュ用の教材番号も更新しています。
採点・再回答・理解チェック・初回レポート・80問の図解・18問の条件変更演習・説明欄・カードの復習予定を引き継いでいます。
同じURLとブラウザでは、同じIDで残したカードの学習状態を引き継ぎます。数値カードを覚えた記録を、新しい概念カードへ流用しません。統合カードは統合先の記録を使います。回答・採点の保存キーは変更していません。
