2022.12.11 FE修了試験｜理解と復習を補強した v3

追加した機能
・全80問：正答への最短ルート、図解と理由、全選択肢比較、自分の言葉で説明する欄。
・18問：利用率、計算量、偶数パリティ、整列、探索、再帰、CPU、アドレス、仮想化、タスク競合、エンディアン、電力量、外部キー、無線LAN、可用性、線形計画、減価償却、損益の条件変更演習。
・説明欄は自動保存。解答例と照合して自己評価し、「説明をもう一度確認する問題」で抽出できます。文章の自動採点は行いません。
・320枚のカードに次回復習を設定。説明できた：1→3→7→14→30日、不安：翌日、説明できない：10分後。「今日の復習」は予定時刻が到来したカードを表示。
・初回の正解数と、再回答採点後の正解数を区別。初回誤答・未解決・説明の要確認で復習できます。

使い方
ZIPを展開してindex.htmlを開きます。GitHub Pagesではフォルダ内のファイルをassetsの階層ごと配置してください。enhancements.js、enhancements.cssを含む全ファイルを更新してください。
同じURL・同じブラウザなら旧版の回答・カード状態を引き継ぎます。旧カードで予定時刻がないものは復習対象になります。保存先はブラウザ内で、端末間同期はありません。
初回採点前にも解説を開ける学習教材です。条件変更演習を開くと正答も表示されるため、自力の初回成績を測るときは先に回答してください。
条件変更は設問に基づく練習であり、元の問題・採点用正答を変更しません。演習独自の仮定は画面内に明記しています。
本教材は当該80問の過去問対策用で、科目Aの全出題範囲や合格を保証するものではありません。
