2022.12.11 FE修了試験｜全80問ビジュアル改訂版 v7

今回の変更
問32で採用した機器・通信・方向が見える表現を踏まえ、残り79問の図を設問別に作り直しました。問32の図はv6のものを維持し、全80問に反映しています。
ビットの点灯、整列の移動、再帰の呼出しと戻り、タスクの時系列、資源や電力量の面積、機器・利用者・組織の関係、会計の数量関係などを使い分けています。
説明用の模式図です。厳密な縮尺や全ての手順を表すとは限りません。追加した数値例は図中に例と表示し、条件変更演習とは区別しています。
図解改訂一覧.mdに各図の主題、diagram-gallery.htmlに全80枚を収録。SVGなので拡大できます。

使い方
ZIPを展開してindex.htmlを開いてください。GitHub Pagesへは、フォルダ内の全ファイルをassetsの階層ごと配置してください。教材番号は20261018-07です。
全80問の正答・問題画像、197枚の重要用語カードと正式名称、条件変更演習、復習予定、採点・保存機能は継承しています。以前と同じURL・同じブラウザで利用する場合は同じ保存キーを使用します。
